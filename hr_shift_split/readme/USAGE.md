From an open slot (coverage gap):

1. Check the coverage of a planning (*Check Coverage*).
2. On a gap line, press **Split in two**, pick the cut time and confirm.
3. Two partial shifts are created; with the cascade module installed,
   one replacement cascade per part is generated, ready to start.

From an assigned line (e.g. an announced absence): select the line and
use the **Split shift** action. The line is freed first, then the same
flow applies.
