One click fills every coverage gap of a weekly planning with the best
available candidate, using the replacement cascade engine (job,
department and availability filters; fewest assigned hours first, then
fairness rotation).

Every assignment is materialized as a filled cascade and an approved
open shift claim, so auto-planning leaves exactly the same audit trail
as a manual cascade — only the consent step is skipped. Slots without
any eligible candidate are reported and left open.
